# Primeiros passos — Job Radar

Este arquivo é um atalho. O manual completo (instalação, configuração, uso no
dia a dia, API, troubleshooting) está no [**README.md**](./README.md).

## Resumão

```bash
git clone https://github.com/T3lo5/job-radar.git
cd job-radar
./dev-up.sh
```

Abra http://localhost:5173 e siga o assistente de configuração.

- **Windows:** `.\dev-up.ps1` no PowerShell (ou `.\dev-up.sh` no Git Bash/WSL)
- **Parar:** `./dev-down.sh` (ou `Ctrl+C` no terminal do `dev-up.sh`)
- **Nunca** use `./dev-up.sh --reset` com dados que importam — ele apaga o banco
